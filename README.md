# EstatePro PRIME (Mirador Prime) — Architectural Real Estate & Capital Investment

A high-converting, luxury real estate web application built for discerning homebuyers and overseas diaspora investors. Features dual-mode design, architectural lighting simulations, multi-currency ROI calculations, and a comprehensive 100-keyword SEO ranking engine.

---

## 🌟 Key Features

- 🌓 **Dual-Mode by Design**:
  - **Twilight Noir (Dark Mode)**: Evening luxury with obsidian backgrounds, subtle glassmorphism cards, and warm champagne gold accents.
  - **Warm Alabaster (Light Mode)**: Gallery-inspired editorial layout with crisp linen cards, soft sandstone tones, and deep charcoal ink typography.
- 🌅 **Architectural Ambience Simulator**: Interactive lighting previews showcasing properties under **Dawn Golden Hour**, **Midday Sunlight**, and **Twilight Noir**.
- 📊 **PrimeYield™ ROI Financial Engine**: Real-time simulation of rental yields, monthly payouts, compounded capital gains, and net returns across multi-year holding periods.
- 💱 **Multi-Currency Support**: Switch between **PKR (₨)**, **AED (د.إ)**, **USD ($)**, and **GBP (£)** with automated price conversions.
- 🔍 **Top 100 Real Estate SEO Keywords**: Interactive search matrix covering high-intent queries across Luxury Residential, Prime Locations, Investment & ROI, Architectural Scales, and Legal & Concierge pillars.
- 📅 **2-Step Private Viewing Booking Modal**: Complete with tour format selection (In-Person, 4K Live Video, VIP Wealth Advisory Call) and confetti celebration.
- 💬 **Sticky VIP Concierge Ribbon**: Instant one-tap WhatsApp concierge integration and phone call scheduler.

---

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 + Custom Dual-Mode CSS Variables
- **Icons & Visuals**: Lucide React + Glassmorphism UI
- **Animations & Effects**: Framer Motion + Canvas Confetti
- **Deployment**: GitHub Pages (Automated GitHub Actions CI/CD)

---

## 🚀 Local Development

```bash
# 1. Install dependencies
npm install

# 2. Start Vite development server
npm run dev

# 3. Build production bundle
npm run build

# 4. Preview production build locally
npm run preview
```
